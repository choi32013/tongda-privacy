개인정보 처리방침

앱 이름: 통다 (Tongda)

패키지: studio.leco.tongda

개발자: Leco (leco.studio)

시행일자: 2026년 2월 16일

📱 통다는 사용자의 모든 데이터를 기기 내부에만 저장합니다.

서버 전송, 클라우드 동기화, 외부 API 호출이 전혀 없습니다. 사용자의 건강 정보는 오직 사용자의 기기에만 존재하며, 개발자나 제3자가 접근할 수 없습니다.

1. 수집하는 정보

통다는 다음과 같은 정보를 수집합니다. 모든 정보는 기기 내부에만 저장됩니다.

  • 통증 기록: 통증 강도(0-10 단계), 신체 부위 그림, 증상 설명, 기록 시간
  • 처방 기록: 처방 유형(약, 운동, 물리치료, 수술, 기타), 메모, 기록 시간
  • 통증 이슈 정보: 통증 이름, 시작 일자, 최종 수정 일자, 상태(진행중/완료)

수집하지 않는 정보:

  • 이름, 이메일, 전화번호 등 개인 식별 정보
  • 위치 정보
  • 기기 고유 식별자
  • 사용 통계 또는 분석 데이터

2. 정보 사용 목적

수집된 정보는 다음 목적으로만 사용됩니다.

  • 사용자의 통증 기록 저장 및 관리
  • 통증 패턴 시각화 (24시간 차트, 월별 달력 히트맵)
  • 통증 이슈별 상세 정보 조회
  • 처방 기록 추적 및 관리

모든 처리는 기기 내부에서만 이루어지며, 외부로 전송되지 않습니다.

3. 정보 저장 및 보안

통다는 모든 데이터를 기기의 로컬 저장소(LocalStorage)에 저장합니다.

  • 저장 위치: 사용자 기기 내부 (앱 전용 저장 공간)
  • 저장 방식: JSON 형식으로 로컬 저장소에 저장
  • 보안: Android 운영체제의 앱 샌드박스에 의해 보호됨
  • 접근 권한: 오직 통다 앱만 해당 데이터에 접근 가능

앱을 삭제하면 모든 데이터가 영구적으로 삭제됩니다. 개발자는 사용자의 데이터를 복구할 수 없습니다.

4. 제3자 제공 및 공유

통다는 사용자의 정보를 제3자와 공유하지 않습니다.

  • 서버로 데이터를 전송하지 않습니다
  • 광고 네트워크를 사용하지 않습니다
  • 분석 도구(Google Analytics 등)를 사용하지 않습니다
  • 제3자 SDK를 포함하지 않습니다 (Capacitor WebView 제외)

인터넷 권한 안내: 통다는 INTERNET 권한을 요청하지만, 이는 Capacitor WebView의 기본 동작을 위한 것입니다. 실제로 네트워크 통신을 수행하지 않으며, 사용자 데이터를 전송하지 않습니다.

5. 사용자 권리

사용자는 다음과 같은 권리를 가집니다.

  • 조회: 기록 화면에서 모든 저장된 데이터를 조회할 수 있습니다
  • 수정: 개별 통증 기록 및 처방 기록을 수정할 수 있습니다
  • 삭제: 개별 기록 또는 전체 데이터를 삭제할 수 있습니다
  • 백업/복원: 설정 화면에서 데이터를 백업하고 복원할 수 있습니다

모든 권리는 앱 내에서 직접 행사할 수 있으며, 개발자의 승인이나 개입이 필요하지 않습니다.

6. 미성년자 개인정보 보호

통다는 연령 제한 없이 모든 사용자가 사용할 수 있습니다. 미성년자의 경우에도 모든 데이터는 기기 내부에만 저장되며, 외부로 전송되지 않습니다.

7. 개인정보 처리방침 변경

본 개인정보 처리방침은 법령 및 서비스 변경에 따라 수정될 수 있습니다. 변경 시 앱 업데이트 또는 GitHub 저장소를 통해 공지합니다.
